Overview

This page characterizes the single long-read RNA-seq dataset we currently have for the stimulated-neuron project.

The file

/project/xinhe/xsun/long_read_RNA/data/NP184_NP187_NP188_combined_DUAN_21-0/
  merged.curated.minimap2.bam       27.5 GB
  merged.curated.minimap2.bam.bai   (older than the BAM — should be regenerated)

Platform and chemistry

Oxford Nanopore + 10x Chromium 3’ v3, aligned with minimap2 splice, to hg38.

Two practical consequences:

  • Always filter with -F 0x900. Secondary alignments are 28% of records and will inflate any naive count.
  • The BAM is already UMI-deduplicated (the “curated” in the filename): 1.01 reads per (cell barcode, UMI) pair. So primary reads ≈ UMIs.

The minimum is 508 reads/cell, so empty droplets were already filtered upstream. 408 cells exceed 20% chrM; 5 exceed 50%.

Read length and splicing

This is the single most consequential property for the isoform plan.

From a genome-wide sample of 450k primary reads across 12 windows:

  • Query length: median 506 bp, mean 624, p90 1,115, p99 2,038, max 5,963.
  • Only 27.3% of reads are spliced (contain a CIGAR N); among those, median 2 junctions, p90 6.

These are largely 3’ fragments, not full-length transcripts — expected for a 10x 3’ library, but it does undercut full-length isoform quantification. Junction-level methods (LeafCutter-style intron clustering) are likely the more robust route than isoform-level quantification, despite the header showing IsoQuant was run upstream.

Contamination and background

  • rRNA carryover is substantial. 677k of 1.31M chr21 primary reads fall in the chr21:8.2–8.6 Mb rDNA array. The rDNA-bearing scaffolds GL000220.1 (2.44M) and KI270733.1 (2.52M) are also heavily loaded (those counts include secondary alignments).
  • chrM is 3.97M mapped reads (~4.6% overall; median 4.2% per cell).
  • Filter rDNA regions and chrM before quantification.
