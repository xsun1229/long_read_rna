The dataset

Long-read (Oxford Nanopore) single-nucleus RNA-seq of hiPSC-derived neurons from the Duan lab — the same cells and donors as Liang et al., Science 392:eadw3949 (2026), assayed on Nanopore rather than the published 10x Multiome. Not itself published.

data/NP184_NP187_NP188_combined_DUAN_21-0/   0 hr   27.5 GB
data/NP189_NP190_NP193_combined_DUAN_21-1/   1 hr   34.2 GB
data/NP191_NP192_NP194_combined_DUAN_21-6/   6 hr   36.4 GB

Coculture batch 21, four donors, three KCl-stimulation timepoints (0 / 1 / 6 h). The three NP identifiers in each name are sequencing runs (flow cells) of that one library — three per library, all distinct across the three files.

Genomic origin of reads

Genome-wide, every primary read, using the 10x Cell Ranger definition — the field standard for 10x data:

Exonic — ≥50% of the read’s aligned bases fall within an exon Intronic — not exonic, but the read overlaps a gene body Intergenic — neither

“Aligned bases” means matched bases only (M/=/X). Soft-clips, insertions, deletions and splice gaps are all excluded from the denominator — the last of these matters, because otherwise every spliced read would be misclassified as intronic. Annotation is the IsoQuant extended GTF.

Three things worth knowing about these numbers:

  • The 50% threshold is not doing much work. The distribution of exonic fraction per read is strongly bimodal — 64.5% of reads have no exonic bases at all and 24% are entirely exonic, with only 1.5% anywhere near the cut. Moving the threshold from 30% to 90% changes the exonic fraction by ~4 points. The result is a property of the data, not of the cutoff.
  • Intron dominance is a size effect, not a capture failure. Exons are only ~9% of genic sequence, so a uniform library would be ~9% exonic. At 36–41% the data is ~4× exon-enriched; introns still win on read count because there is ~11× more intronic sequence.
  • Do not use chr21 as a proxy for this. chr21 alone gives 29.0% exonic / 65.0% intronic at 0 hr — 7–8 points off the genome-wide value, because it is unusually intron-heavy (345 lncRNA vs 190 protein-coding genes).

The 1 hr shift toward exonic (+4.7 points) and away from intronic (−4.1) is consistent with post-stimulation transcript maturation, and the same shape appears in the collaborators’ independently computed QC numbers. Treat it as suggestive until tested within donors — library-level differences in nuclear/cytoplasmic capture would produce the same pattern.

Two scNanoGPS conventions differ from what single-cell tooling expects:

  • the cell barcode is in the RG tag, not CB
  • the UMI is appended to the read name, not in UB
QNAME  281b9c59-a0da-477b-84b9-d9895f6ec585_TTCAAGATATAT
RG:Z:  TTCGTTAGTACCAGGT

This is convenient for one thing: samtools view -R <barcode_list> splits a BAM by donor directly, with no re-tagging.
