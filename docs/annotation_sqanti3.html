What was run

data/reference/OUT.extended_annotation.gtf is the annotation we were given with the data — the 10x reference plus transcripts assembled from the long reads themselves. To find out what those extra transcripts actually are, we classified the whole file with SQANTI3 (6.sqanti3/).

Query OUT.extended_annotation.gtf — all 247,450 transcripts
Reference GENCODE v44 — the release 10x refdata-gex-GRCh38-2024-A is built from
Genome 10x 2020-A FASTA (same GRCh38 sequence; all 194 contigs match the BAM)
Runtime 27 min, 12 cores

Two checks before trusting the output: all 224,960 reference ENST transcripts in the query are present in v44 (so the reference version is right), and all 47 GENCODE contigs exist in the FASTA. We classified the whole annotation rather than just the extra transcripts, so the reference ones act as a built-in control — they must come back as full-splice matches.

Of the genes, 37,933 are reference ENSG; the other 1,945 are new loci. 22,490 of the transcripts are not in the 10x reference.

Known vs novel

SQANTI3 assigns every transcript one structural category:

Category Transcripts % Meaning
full-splice_match (FSM) 225,023 90.9 splice chain matches a reference transcript exactly
incomplete-splice_match (ISM) 13,498 5.5 splice chain is a contiguous subset of a reference transcript
novel_not_in_catalog (NNC) 3,247 1.3 uses at least one splice site absent from the reference
novel_in_catalog (NIC) 2,176 0.9 new arrangement of splice sites that all exist in the reference
antisense 1,595 0.6 opposite strand of a known gene
genic_intron 958 0.4 entirely inside an intron
genic 444 0.2 overlaps a gene but fits no cleaner class
intergenic 371 0.1 outside any annotated gene
fusion 138 0.1 spans two genes

The control passed: 225,023 FSM against 224,960 reference transcripts. The 63 extra are transcripts that exactly match a v44 transcript which 10x’s filtered reference happened to exclude.

Most of the extra transcripts are fragments, not new structures

Of the 22,490 transcripts beyond the reference, only 2,176 NIC + 3,247 NNC ≈ 5,400 (2.2% of the annotation) are genuinely novel splice structures. The largest group by far — 13,498 — is ISM: contiguous subsets of transcripts already in the reference. The subcategories say what kind:

ISM subcategory Count
5′ fragment 11,118
internal fragment 1,088
3′ fragment 863
intron retention 429

For the novel ones: new exon combinations, or retained introns?

Combinations dominate:

Subcategory Count
NIC (2,176) combination of known splice sites 945
combination of known junctions 880
intron retention 351
NNC (3,247) at least one novel splice site 3,122
intron retention 125

Intron retention across the whole annotation:

Category Retained-intron transcripts
incomplete-splice_match 429
novel_in_catalog 351

Total 915

So of ~5,400 genuinely novel transcripts, ~1,825 are rearrangements of known splice sites, ~3,122 introduce a new splice site, and only 476 are intron-retention events. Retention is real but a minor mode — 915 transcripts in the entire annotation.
