What this page covers

Two related questions about what the reads actually are, both answered on chr21 for all three timepoints (2.29 M primary reads):

  1. Where do reads fall — exon, intron, or intergenic, and by what rule?
  2. What exon structure does each read support — which numbered exons it covers and how they are joined?

Scripts: 4.read_structure/ — 1.annotate_read_structure.py does the per-read CIGAR work, 2.summarise_structure.R does the summary stats. Outputs in long_read_processed/read_structure/.

The chr21 BAM excludes the rDNA array (chr21:8.2–8.6 Mb), which otherwise contributes ~677 k rRNA carryover reads and would distort every fraction on this page.

Part 1 — exon / intron / intergenic

The criterion

There is no canonical definition, so it has to be stated explicitly. For each primary read:

  1. Parse the CIGAR into aligned reference blocks. M/=/X extend a block; N (splice) and D break it; I/S/H consume no reference. This matters — 97.8% of reads are soft-clipped, and counting clipped bases as aligned would corrupt every number below.
  2. Merge all annotated exons into a flat interval set, and separately all genes. On chr21: 3,710 merged exon intervals, 328 gene intervals.
  3. Compute two fractions per read — f_exon = aligned bases in exons / total aligned bases, and f_gene likewise.
  4. Classify:
f_gene < 0.5                   -> intergenic
f_gene >= 0.5 and f_exon >= 0.5 -> exonic
f_gene >= 0.5 and f_exon < 0.5  -> intronic

The rule is majority of aligned bases, not “touches an exon”. A read that clips one exon and then runs 400 bp into an intron is intronic, which is the behaviour you want for nuclear RNA.

How much the rule changes the answer

Same reads, three rules, 0 hr:

Rule Exonic Intronic
Permissive — any exon overlap 35.50% 58.55%
Majority — ≥50% of bases 29.00% 64.82%
Strict — ≥90% / ≤10% 26.58% 59.89% (+7.35% mixed)

Exonic swings between 26.6% and 35.5% on the choice of rule alone. Any single “% exonic” figure is meaningless without the criterion attached.

Introns dominate because they are large, not because enrichment failed

On chr21 exons are only 8.9% of genic sequence (1.86 Mb of 21.0 Mb). If reads landed uniformly across genes, 8.9% of genic bases would be exonic. Observed:

Exonic share of genic bases Enrichment over uniform
0 hr 32.6% 3.7×
1 hr 35.8% 4.0×
6 hr 35.5% 4.0×

So the library is strongly exon-enriched, ~4×, and introns still dominate the read count simply because there is ~11× more intronic sequence. This is a normal single-nucleus library, not a failed one.

Reconciling with the scNanoGPS slides

The slides report 68.40% intronic / 11.62% exonic. Our intronic (64.8%) is close; our exonic (29.0%) is not.

That gap is the criterion, not an error in either number. Their “exonic” is almost certainly transcript compatibility — the read must be consistent with an annotated exon structure — which is much stricter than base overlap. Consistency check: only 19.43% of reads are spliced at all, so a rule requiring validated junction structure caps out near 19%, and 11.62% sits plausibly below that.

Two caveats on our numbers: we used the IsoQuant extended annotation, which adds 22,490 novel transcripts and therefore inflates “exonic” relative to plain GENCODE; and this is chr21 with the rDNA array removed.

Part 2 — per-read exon structure

Exon numbering

Per-transcript numbering is ambiguous — the same physical exon is #3 in one isoform and #5 in another. Instead we flatten: the union of all exons of all transcripts of a gene, merged, numbered 1..N in 5’→3’ order (reversed on the minus strand). This matches isoLASER’s exonic-part model, so the two analyses are directly comparable.

Notation

E1-E2-E3   consecutive exons joined by splice junctions
E1-E3      E2 bypassed
E1=E2      contiguous alignment through the intron (retention, >=50% covered)
E4         single exon, no junction
INTRONIC   assigned to a gene but no exon covered (>=10 bp to "cover")
INTERGENIC not assignable to a gene

An artifact that had to be fixed first

The first pass gave SKIP (46,485 reads) greater than CONSECUTIVE (40,321), and the most common pattern on the chromosome was SON E1-E2-E4. That is not exon skipping. The union numbering inserts rare isoform-specific exons into the sequence:

Gene “Skipped” exon Size Transcript support
SON E3 39 bp 1 / 23
ATP5PF E3 43 bp 1 / 8
SOD1 E3 186 bp 1 / 5

SON E1-E2-E4 is the canonical structure — it only looks like skipping because a 1-of-23 exon occupies position 3.

Fix: skip-calling is now transcript-aware. A bypassed exon must be present in ≥2 transcripts to count as skipping; otherwise the read is SKIP_MINOR. After the fix SKIP is 2.51% and sits below CONSECUTIVE at 6.41%.

This bias is inherited by any analysis that flattens the IsoQuant extended annotation — including how we read isoLASER’s exonic parts.

The 3’ bias, measured directly

Every top single-exon pattern is a terminal exon — APP E27, COL6A1 E35, TTC3 E54, BRWD1 E42. Quantified over single-exon reads in genes with ≥5 exons (n = 110,412, 0 hr):

Position along gene (5’→3’) Share of reads
first 20% 15.6%
20–40% 10.1%
40–60% 7.4%
60–80% 13.3%
last 20% 53.6%

41.7% cover the final exon; 3.2% cover the first — a 13× ratio.

This is the 10x 3’ chemistry appearing directly in the structure annotation, and it is the cleanest statement of the dataset’s core limitation: reads sample the 3’ end, so splicing information is concentrated at the 3’ end of genes and there is little power over 5’ events.

Caveats

The 27% all-novel junction rate is too high to be discovery. The IsoQuant extended annotation already contains 22,490 novel transcripts, so genuinely unannotated junctions should be rarer than this. The likely cause is the 5 bp matching tolerance against ~1.1% ONT base error — minimap2 placing junctions a few bases off the true site. Before any of these are read as novel splicing the tolerance needs calibrating against splice-site motifs (GT-AG). The novel-junction numbers should not be reported yet.

The timepoint trends are small and donor-pooled. Exonic rises 29.00 → 32.58 → 32.05%, intronic falls 64.82 → 61.60 → 62.65%, and supported skipping rises 17.35 → 19.10%. The direction is consistent with post-stimulation transcript maturation, and 0 hr separates from both stimulated points (~3 pp) while 1 hr and 6 hr differ from each other by ~0.5 pp. But donors are pooled and this is one chromosome — library-level differences in nuclear/cytoplasmic capture would produce the same pattern.

It is worth noting that this trend is independent of the barcode metadata, so it serves as a weak cross-check on the timepoint labels alongside the planned IEG measurement.

Annotation choice matters. All of the above uses the IsoQuant extended annotation. A plain GENCODE run would give fewer flattened exons, fewer SKIP_MINOR calls, and a lower exonic fraction.

What this implies for the two aims

Aim 1 (splicing changes during the response). With ~60% of reads intronic and only 9.5% carrying multiple exons, isoform-level quantification discards most of the data. Junction-level counting and intron retention use what is actually present. Intron retention in particular is well matched to nuclear RNA and is measured per molecule by long reads.

Aim 2 (genetic variants associated with splicing). The 3’ bias localises where power exists: a heterozygous SNP and a splicing event must fall on the same read, and both are concentrated in terminal exons. This is consistent with the 98.5% untestable rate seen in the chr21 isoLASER run.

Next steps

  • Run this per donor × timepoint (12 groups) so the trends can be tested within donors rather than on pooled data.
  • Calibrate the junction-matching tolerance against GT-AG motifs before reporting anything about novel junctions.
  • Extend genome-wide once the full GRCh38 FASTA is in place.
