Two conventions inherited from scNanoGPS are worth knowing, because most single-cell tooling assumes otherwise:

  • the cell barcode lives in the RG tag, not CB
  • the UMI is appended to the read name (<ONT-UUID>_<12bp UMI>), not in UB

Always filter with -F 0x900. Secondary alignments are 28% of records and inflate any naive count — unevenly, since they concentrate in repeats.

The BAM is already UMI-deduplicated: 1.01 reads per (barcode, UMI) pair, so reads ≈ unique molecules.

Read characteristics

Median read length 506 bp (mean 617, p90 1,115, max ~6 kb)
Reads containing a splice junction 27.3%
Median per-read error rate ~1.1%
Soft-clipped reads 97.8%
Reads with no base-quality string 20.5% (QUAL = *)

The near-universal soft clipping is untrimmed polyA/adapter. It turns out to be harmless for isoLASER (its large_soft_clip filter removed only 225 of 585,767 reads).

The missing base qualities are more consequential than they look. Besides mattering for variant calling, mixed QUAL/no-QUAL reads silently break samtools fastq: it reported processed 629035 reads while writing only 14,255 — a 97.7% loss with no error. Splitting the input by QUAL presence converts both halves correctly, so it is the interleaving that breaks it. Convert with an explicit parser instead.

Genomic context — mostly intronic

Read midpoints against the IsoQuant annotation, chr21:

Ours (chr21) scNanoGPS, genome-wide [slides]
Exonic 19.5% 11.6%
Intronic 74.2% 68.4%
Intergenic 6.3% 20.0%

This is the single most important property for the splicing aims. It is single-nucleus RNA, so the library is dominated by unspliced nuclear pre-mRNA. Reads sitting in introns cannot be assigned to a mature transcript, which is exactly what exon-centric isoform methods require.

It directly explains the largest loss in the isoLASER pilot (unassigned_tx_id = 53.8% of reads). That is inherent to the assay, not a tunable parameter.

Background to filter

  • rRNA carryover — 677 k of chr21’s 1.31 M primary reads lie in the chr21:8.2–8.6 Mb rDNA array. The rDNA scaffolds GL000220.1 and KI270733.1 are also heavily loaded.
  • Mitochondrial — ~4.6% of reads overall, median 4.2% per cell.
  • Rat astrocytes were in the coculture [metadata]. They are filtered out of the metadata file, but rat-derived reads may still be in the BAM.

The unassigned cells look lower quality — mean 8.2% mitochondrial versus 4.7% for assigned cells — so they are largely cells that failed QC in the published analysis.

The slides report 5,035 cells with a confident cell line [slides]. Ours is lower because the mapping file we hold is restricted to cells also assigned to GABA/nmglut/npglut, i.e. it is the intersection of the cell-line and cell-type calls. For allele-specific splicing only the donor matters, so the unfiltered cell-line list would be preferable.

Sex verified independently

Scoring each cell on chrY-specific genes (PAR excluded) versus XIST gives 47% male among assigned cells, consistent with the 2M/2F design.

Worth recording as a cautionary note: before the donor labels arrived, the same test on all 8,612 cells gave 65% male. The calls it made were 98% accurate, but coverage was badly asymmetric — female cells went unassigned 55% of the time versus 14% for male, because one XIST locus is a weaker detector than nine pooled chrY genes. The method was sound; the marginal totals were not.

Stimulation state — 0 hr only

The published design has three timepoints per batch (0 / 1 / 6 h after 53 mM KCl), so batch 21 has libraries 21-0, 21-1, 21-6. Matching our 8,612 barcodes against each:

Library Timepoint Barcodes Overlap with our BAM
21-0 0 hr, unstimulated 5,592 4,866 — 87.0%
21-1 1 hr 9,760 43 — 0.4%
21-6 6 hr 7,895 48 — 0.6%

The 0.4–0.6% is what random 16-mer collisions between independent 10x libraries would give. So this BAM is the unstimulated library only, and NP184/NP187/NP188 are most likely three sequencing runs of it rather than three timepoints.

What this means for the analysis

Splicing changes during the neuronal response cannot be done with this file: there is no stimulated condition in it. It needs the 21-1 and 21-6 BAMs.

Allele-specific splicing is feasible now. We have four donors with direct barcode-level assignment, so no genotype demultiplexing is required. The route is: split the BAM per donor → run isoLASER per donor → isolaser_joint across the four. See the isoLASER page.

Two caveats to size expectations:

  • Four donors is a small cohort for anything genetic — the paper used 100 lines for its QTL mapping. What is realistically deliverable is allele-specific splicing within donors plus cross-donor consistency.
  • Read retention through isoLASER is 14.8% (measured on chr21), dominated by the intronic fraction above. And 97% of tested events were untestable for linkage, because a heterozygous SNP and the splicing event must fall on the same ~506 bp read.

Open questions

  4. At what stage were the base qualities lost for 20% of reads?
